## ✦ Overview

A high-end restaurant website demo built for **UK restaurant owners** and luxury hospitality client acquisition.

Instead of generic restaurant templates, ecommerce grids and white-card layouts, this project delivers an **editorial campaign experience** with:

> Oversized typography · Cinematic image reveals · Scroll-driven choreography · Seamless micro-interactions

---

## ✦ Experience

| Section | What it does |
| :-- | :-- |
| **Cinematic Hero** | Full-screen video background with a staggered serif headline reveal |
| **Editorial Story** | Asymmetric 12-column layout with gold hairline borders |
| **The Living Menu** | Hover a dish title and the featured photo changes live |
| **Dish Detail Overlay** | 55 / 45 split modal with ingredients, allergens and a booking CTA |
| **Chef Spotlight** | Three-image composition with an arch clip-path reveal |
| **Atmosphere Gallery** | 8-image masonry grid with a cinematic lightbox |
| **Testimonials** | Editorial guest review cards |
| **Reservations** | Booking form that sends to WhatsApp or Email |
| **Visit** | Opening hours, location details and a Google Maps link |

---

## ✦ Tech Stack

| Technology | Role |
| :-- | :-- |
| **React 19** | Component architecture, custom hooks, Home ↔ Menu navigation |
| **Vite 8** | Instant dev server with HMR, optimized production build |
| **Tailwind CSS v4** | Dark luxury theme, noise overlays, custom scrollbars |
| **GSAP + ScrollTrigger** | Clip-path image reveals, line-by-line text choreography |
| **Framer Motion** | Overlays, lightbox, mobile drawer, animated category tabs |
| **Lenis** | Smooth momentum scrolling, synced with the GSAP ticker |
| **Lucide React** | Minimal, consistent icon set |

## ✦ Feature Details

<details>
<summary><b>Navigation</b></summary>
<br/>

- Glassmorphic top bar with backdrop blur
- Animated underline hover on desktop links
- Full-screen mobile drawer with staggered entrance
- Persistent **REQUEST A TABLE** call-to-action
</details>

<details>
<summary><b>Hero</b></summary>
<br/>

- HTML5 video background with image fallback
- Staggered serif headline reveal
- Animated scroll indicator with ✦ accents
</details>

<details>
<summary><b>Menu</b></summary>
<br/>

- Interactive home preview with live image swap on hover
- Dedicated menu page with sticky numbered categories (`01 STARTERS` · `02 MAINS` · `03 DESSERTS`) and live dish counts
- Alternating chapter layouts with price, ingredients and allergen tags (`GF` · `V` · `VE`)
</details>

<details>
<summary><b>Dish Overlay</b></summary>
<br/>

- Photography on the left, full details on the right
- `Esc` to close, body scroll-lock, direct table request trigger
</details>

<details>
<summary><b>Gallery Lightbox</b></summary>
<br/>

- Keyboard navigation (`←` `→` `ESC`)
- Counter (`03 / 08`), title captions, backdrop blur
</details>

<details>
<summary><b>Reservations</b></summary>
<br/>

- Date, time, guest count and special requests
- One-click send via WhatsApp (`wa.me`) or a pre-formatted `mailto:` link
</details>

## ✦ Getting Started

Requires **Node.js 18+** and npm or yarn.

```bash
npm install        # install dependencies
npm run dev        # start the dev server
npm run build      # build for production
npm run preview    # preview the production build
```
